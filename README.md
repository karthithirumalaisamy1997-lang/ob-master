# Operation Bulletin

A Vite-based project scaffold for the Operation Bulletin (OB) app.

## Setup
```bash
npm install
npm run dev      # local dev server
npm run build     # production build into /dist
npm run preview   # preview the production build locally
```

## Deploy
Push this repo to GitHub, then deploy `dist/` (after `npm run build`) via GitHub Pages,
Netlify, or Vercel.

See `src/README.txt` for notes on where the app source lives.
